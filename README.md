# ポケモン図鑑

## 機能概要

ポケモンのデータを取得する API 「[PokéAPI](https://pokeapi.co/)」を使用したポケモン図鑑です。

## 工夫した点・学び

### API からの情報取得

API からデータを fetch することで、非同期処理の理解を深めた。

### CSS によるスタイリング

CSS を用いることでデザインや簡単なアニメーションの設定方法を理解した。

### JSON ファイルの活用

PokéAPI から返ってくるデータは英語のため、JSON ファイルに英名と日本語名を保存し、それを利用して翻訳した。  
日本語名で取得する API も存在するが、JSON の勉強のため、この方法を採用。

### TypeScript の採用

まずは JavaScript で大枠を作り、その後 TypeScript に変えることで、とっかかりの難易度を下げつつ型安全を学んだ。
